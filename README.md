# Stash

My personal dumping ground for ideas, experiments, and random projects.

## Structure

```
ideas/       - Quick thoughts, concepts, and half-baked plans
projects/    - Standalone mini-projects and experiments
snippets/    - Useful code snippets and one-off scripts
notes/       - Reference notes, research, and learning logs
```

## How to use

- Drop ideas into `ideas/` as markdown files
- Start new experiments in `projects/` with their own subfolder
- Save reusable code in `snippets/`
- Keep research and notes in `notes/`

Nothing here needs to be polished. That's the point.
